**貫穿所有版本的三條原則：**
1. 身體不是固定骨架，是部位之間關係的表現。
2. 跨物種靠語意對應，不靠共同祖先。
3. 遺傳作用在基因上，不在長好的形狀上做平均。

## 五、名詞表

**專案自己的詞**

| 詞 | 意思 |
|---|---|
| 特徵（trait） | 舊版本裡身體的一個單位（例如毒牙、觸手），帶語意標籤 |
| BodyGraph | 舊版本裡由特徵連成的圖，就是一隻生物 |
| PCE | Part Correspondence Engine。用語意標籤算兩個部位有多像，決定誰對應誰 |
| 加權 Jaccard | 兩組標籤「共有的」除以「全部的」，部位層標籤算 2 倍、器官層 1 倍、細胞層 0.5 倍 |
| ontology／三層標籤 | 標籤的分類表：細胞層、器官層、部位層 |
| 基因組（genome） | 一隻生物的全部基因。現行版本裡是一串骨頭的數值 |
| 骨頭鏈 | 一個部位裡首尾相接的幾根骨頭 |
| 隱式曲面／距離場 | 不直接畫表面，而是算「空間中每一點離骨頭多遠」，在某個距離處取出表面 |
| 平滑聯集 | 把兩個形狀融在一起，交界處圓滑過渡 |
| 封閉網格（水密） | 表面沒有破洞，裡外分得清楚 |
| 傅立葉細節層 | 用幾個波疊加，讓部位的截面不只是圓形 |
| 機率配對 | 分數在 0.25–0.40 之間的部位，依機率決定算不算一對 |
| 相對基因 | 部位的大小與位置相對於身體記錄，移到別種身體上會跟著縮放 |
| 連鎖 | 同一個部位上的基因傾向一起來自同一方；每個部位只有一個交換點 |
| 嫁接 | 沒配到對象的部位整個接到子代身上 |
| 位置規則 | 兩個部位落在同一個接點時只留一個 |
| 念珠狀身體 | 身體沿長度方向出現一串多餘的隆起 |
| 擁擠／被吞掉 | 一個部位埋在另一個部位裡，幾乎看不到 |
| 氣泡 | 封在身體裡面的小空洞 |
| 部位屬性層 | 肢體的數量與屬性（長度、粗細、漸細、彎曲）分開遺傳；預設關閉 |
| 形體包 | 交給動作系統的資料：部位、骨頭、頂點權重、血緣 |
| 滿射 | 所有可能的遺傳組合都有機會出現 |
| System A／System B | 4 月的劃分：語意與遺傳／3D 網格。現在已不用這個劃分 |
| RTISV2 | 5 月寫的精簡實驗版，只有特徵圖 |
| ATMS | 你的動作系統（另一個專案） |
| 佛光 | v1 裡 seed 888 自發長出的浮動光環 |

**實驗與統計的詞**

| 詞 | 意思 |
|---|---|
| 種子（seed） | 亂數的起點；同一個種子重跑會得到相同結果 |
| n | 重複了幾次（幾個種子） |
| 對照組 | 除了要測的那件事以外，其他條件都相同的一組 |
| p 值 | 如果兩組其實沒有差別，看到這麼大差距的機率；通常小於 .05 才算顯著 |
| Cohen's d | 差距有多大（0.2 小、0.5 中、0.8 大） |
| power analysis | 事先算需要多少個樣本才看得出差別 |
| 消融（ablation） | 一次拿掉一個部件，看結果差多少 |
| 選擇壓力 | 比較好的個體比較容易留下來 |
| 菁英錦標賽選擇 | 最好的直接保留，其餘兩兩比較、留下較好的 |
