## 怎麼跑（PowerShell）

不需要設定 PYTHONPATH，腳本會自己找 `..\code` 與 `..\..\rtis`。

```powershell
cd D:\ai-research-lab\RTIS\current_2026-11\experiments
python precheck_v1.py                         # 前置檢查 1、3、4、5
python run_v1.py --pilot --workers 2          # 預跑
python precheck_v1.py --pilot pilot           # 七項全部
python run_v1.py --exp X1 --workers 6         # 正式：X1（7,650 個子代）
python run_v1.py --exp X2 --workers 6         # 正式：X2（9,180 個子代）
```

`--workers` 設成 CPU 核心數減 1 左右。中斷後用同一個指令重跑即可：已完成的列保留並跳過；失敗的列只寫一次（`status=error`），不會重跑。程式改過之後，寫進同一個資料夾會被擋下，要換新的 `--out`。

## 寫程式時定下的細節（不是改計畫）

- 亂數：`SeedSequence([20261116, 配對, 方向, 種子, 用途])`；用途 0＝配對、1＝遺傳、2＝基準的隨機抽取。「標籤打亂」與「屬性層」也用用途 2（這兩個條件沒有基準抽取，不會衝突）。
- 「標籤打亂」只在非根部位之間打亂；根部位本來就固定配根部位，不看標籤。
- G3、G4 把每一份（左右、放射的每一份）當成一個實體；同一個基因的其他份，對 G3 算「其他部位」。
- G3 的實心照生成時的加粗（小於 0.9 格的半徑當成 0.9 格）。
- G4：部位單獨長不出表面時記 NaN，算看不見。
- G8：每個子代部位都以 3n＋3 個基因計（n＝骨頭數），用部位記錄的 A 比例（整個複製的部位是 1 或 0）。
- G6、G7 只看「最後還在、由一個 A 部位與一個 B 部位交配而成」的部位。屬性層開啟時，同一組肢體可能共用來源，只有記錄裡有兩個來源的部位才算。
